## Пять минут после покупки

1. Купить `ortusdigital.ru`.
2. Завести ящик `hello@ortusdigital.ru` (почта на домене, например Яндекс 360
   для бизнеса или почта регистратора). Без ящика `email` не вписывать —
   иначе на витрине снова появится контакт, который никуда не доставляет.
3. В `site.config.json` вписать `"origin": "https://ortusdigital.ru"` и,
   когда ящик заработал, `"email"`.
4. `npm test && npm run build` — сборка падает, если что-то не так.
5. Выложить `dist/` на хостинг, направить домен.
