# Показ: сайт агентства «Ортус»

**Живой ссылки нет** — домен не куплен (кандидат `ortusdigital.ru`, см. `ДОМЕН.md`).
Демо-стенд одной командой (нужны только Node и Python 3, зависимостей нет):

```
cd "~/Projects/айти агенство/Ортус-агентство/сайт"
npm run demo        # собирает dist/ с адресом-заглушкой и открывает http://localhost:8080
```

Логина нет — это публичный сайт.

## Сценарий показа (три шага)

1. **Главная, первый экран** (390 и 1280): что это — сайты, реклама, ИИ и 1С одним
   подрядчиком; для кого — малый и средний бизнес; цена — «ниже на этой же
   странице»; одна кнопка «Получить расчёт и сроки».
2. **Прокрутка:** 12 услуг → три сильных направления → четыре настоящие работы
   со скриншотами (без выдуманных процентов, это сказано прямо) → «Как работаем»,
   четыре шага от заявки до отчёта → прайс «от …» по 14 позициям → вопросы.
3. **Заявка** (форма внизу главной или «Контакты»): пустая отправка — ошибка у поля;
   `12` в телефоне — «Проверьте формат»; нормальные данные — «Заявка у нас».

## Чего не обещать

- **Не отправлять форму на показе.** Она уходит на Formspree `mzdlnbpw`, и чья это
  форма, владелец ещё не подтвердил (блокер из `vitriny-blokery.md`).
- Цифр по клиентам нет и не будет, пока клиент не разрешит. Сроки в шагах —
  «в день заявки», «1–2 дня» — это обещание владельца, а не замер.
- Прямых контактов (телефон, Telegram, почта) нет: поля пусты в `site.config.json`.
  Страница «Контакты» честно говорит, что связь только через форму.
- «Команды специалистов по каждому направлению» нет, и сайт больше этого не говорит:
  «один ведущий + специалист под задачу».
