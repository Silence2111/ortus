# Foksten — сайт цифрового агентства

Статика (HTML/CSS/JS), 23 страницы: главная, хаб услуг, 12 страниц услуг,
О нас, Контакты, Кейсы, Блог (+3 статьи), Стать партнёром, Политика.
SEO-разметка (meta, Open Graph, Schema.org), sitemap.xml, robots.txt.
Формы на Formspree.

## Публиковать можно только собранное

Исходники — шаблоны. Домен и контакты в них не зашиты, вместо них
`{{SITE_ORIGIN}}`, `{{CONTACT_EMAIL}}` и условные блоки. Причина: в первой
версии домен стоял в 25 файлах и ~160 местах, и там полгода жил `ortus.ru` —
домен **чужой компании**. Вся SEO-разметка и все репосты работали на чужой
бренд, потому что поправить его нужно было в двадцати пяти местах.

```
npm run check     # проверить конфиг, ничего не собирая
npm run build     # исходники + site.config.json → dist/
npm test          # 38 тестов: не врёт ли витрина и «Студия»
```

`npm run build` **падает**, если домен не задан или если в него вписали
`ortus.ru`. Раздавать хостингу нужно `dist/`, а не корень репозитория.

## Один шаг при покупке домена

Купить домен → вписать одну строку и собрать:

```
SITE_ORIGIN=https://ortusdigital.ru npm run build
```

или один раз прописать в `site.config.json` → `"origin"`. Больше домен
нигде не встречается.

## Что настраивается тем же конфигом

| Поле | Переменная окружения | Если пусто |
|---|---|---|
| `origin` | `SITE_ORIGIN` | **сборка падает** |
| `email` | `SITE_EMAIL` | блока «Email» и ссылки в футере нет, `contactPoint` из JSON-LD убран |
| `telegram` | `SITE_TELEGRAM` | карточки Telegram нет |
| `whatsapp` | `SITE_WHATSAPP` | карточки WhatsApp нет |
| `phone` | `SITE_PHONE` | телефона нет |
| `legal` | `SITE_LEGAL` | строки реквизитов нет |
| `metrikaId` | `SITE_METRIKA_ID` | счётчик не грузится и не делает запросов |

Правило одно: **незаданный канал не рисуется вовсе**. Мёртвая кнопка хуже
отсутствующей. Когда не задан ни один прямой контакт, страница контактов
честно говорит, что единственный рабочий способ связи — форма.

## Выбор варианта дизайна

Вариант ещё не выбран, поэтому на стенде работает переключатель в правом
нижнем углу. Семь вариантов:

| Вариант | Что это |
|---|---|
| **Aurora** | базовый: ирис `#5A5FE0` → мята `#37B6A6`, светлый фон, пятна за героем, градиенты |
| **Системный** | личная дизайн-система: синий `#225AEA`, плоско, без градиентов и свечений |
| **Тёмный** | палитра макета `дизайн-версии/ortus-dark`: чёрный `#0C0C0C`, Montserrat, пурпур `#B600A8`, металлический градиент в заголовке |
| **DesignPro** | палитра макетов `designpro-hero` и `ortus-designpro`: чёрный, Inter, голубой `#64CEFB` |
| **Студия** | **своя вёрстка** по референсу rondesignlab — см. ниже |
| **Стройка** | тема hazard из дизайн-системы: сигнальный жёлтый под оффер ИЖС |
| **Спокойный** | тема calm-case: белый фон, тёмно-синий текст, лёгкие веса |

```
npm run stand        # стенд с переключателем: http://localhost:8080
```

Без `SITE_SKINS=1` переключатель в сборку не попадает — на витрине для клиентов
его быть не должно, и это проверяется тестом. Выбор запоминается в браузере;
отдельный вариант открывается ссылкой, например `?skin=system`.

Шесть вариантов живут в `skins.css` как наборы токенов поверх базового слоя
страниц. Палитры «Тёмного» и «DesignPro» сняты с React-макетов в `дизайн-версии/`;
приёмы вроде magnetic hero и видео на первом экране скином не передаются, их
смотреть в самих макетах (`npm run dev` в папке макета).

### «Студия» — отдельная вёрстка

Палитрой «Студию» не передать: её приёмы требуют другой разметки. Поэтому она
собирается своим набором страниц в `dist/studio/` под теми же именами, а
переключатель переводит на ту же страницу там и обратно.

- **Откуда:** референс `~/.claude/design-refs/rondesignlab` и тема studio из
  дизайн-системы. Интерфейс чёрно-белый, акцент — чёрный, одно наведение на
  всё — инверсия за 0,3 с; теней нет, радиусы 30/46; цвет дают пастельные
  подложки и скриншоты работ.
- **Приёмы:** шапка из плиток; пилюля посреди заголовка (у референса там фото
  людей — фото у нас нет, придумывать их нельзя, поэтому иконка на пастели);
  разделы названы сомнениями клиента («Это те, кто мне поможет?», «Им можно
  доверять?»); между разделами — реплики, как сообщения в чате, с «печатает…»;
  карусель услуг; плита кейса с фактами;
  план с прилипшим заголовком; огромный знак в подвале; карточка «ответим
  сегодня» в углу.
- **Иконки, а не эмодзи:** тонкие линейные из дизайн-системы без цветной
  подложки, в один тон (`studio/icons/`). Эмодзи в «Студии» нет — это
  проверяет тест.
- **Шрифт:** Wix Madefor Display. У Urbanist из референса нет кириллицы —
  русский текст падал в системный шрифт; сравнение — `ПРОДУКТ/студия/шрифты.png`.
- **Честность:** отзывов нет — раздел «Им можно доверять?» говорит это прямо и
  отвечает договором и оплатой по этапам.
- **Цвет и металл:** крупные плиты — мягкое свечение под матовым стеклом с
  зерном (`.st-glow`), пилюли в заголовках и значки проектов — то же свечение
  в миниатюре; пилюля первого экрана — матовое серебро (`.st-chrome`).
  Плоских пастельных заливок нет: владелец назвал их «колхозом».
- **Сайт многостраничный:** работы живут на своей странице, на главной —
  только фраза со стрелкой и плита одного кейса со ссылкой туда. Скриншоты
  показываются окном браузера на фоне в цвет проекта (`.st-win`). Цифры в кейсе — факты о своём
  продукте (3 площадки, 1 400+ автотестов, 60 дней истории), цены — те же, что
  в «Полном списке услуг» (тест сверяет).

Как устроено (`studio/studio.mjs`):

| Что | Где |
|---|---|
| главная, услуги, работы, «О нас», контакты | свёрстаны руками: `studio/pages/*.html` — только содержимое страницы |
| 12 страниц услуг, оффер ИЖС, блог, статьи, партнёрам, политика | преобразование исходной страницы: тексты берутся из неё, правка исходника доезжает сама |
| голова страницы | из исходника (title, Open Graph, JSON-LD) + `noindex`, canonical на исходную |
| форма | та же отправка (`form.js`), поля услуги — из исходной формы |

Если «Студию» выберут основной, её страницы нужно будет собирать в корень
вместо исходных — до выбора они живут только на стенде.

## Прод — с 10.10.2026

**https://a3.201-34-159-41.nip.io/** — дизайн «Студия», российская коробка
lerti (201.34.159.41, Timeweb Новосибирск), nginx + Let's Encrypt.

```
деплой/выкатить.sh            # тесты → сборка из git archive HEAD → выпуск
деплой/выкатить.sh --nginx    # то же + конфиг nginx (деплой/a3.nginx.conf)
деплой/выкатить.sh --откат    # вернуть предыдущий выпуск
```

- Выпуски — `/var/www/a3/releases/`, `current` — ссылка на действующий,
  последние пять хранятся. Незакоммиченные правки на прод не уезжают.
- **Почему не GitHub Pages:** зарубежный хостинг ТСПУ для посетителей из РФ
  обрывает на ~16 КБ — белый экран (так было с RateSpot 07.10.2026).
  Pages теперь только переадресует старые адреса `silence2111.github.io/ortus/`
  на прод (`деплой/pages-переадресация.mjs`, workflow на push в main).
- Доступность проверять с коробки и check-host (узлы ru1–ru3), а не с мака:
  nip.io с мака идёт через VPN.

### Все варианты дизайна — всегда под рукой

- **https://a3.201-34-159-41.nip.io/stend/** — все семь вариантов с
  переключателем в углу, закрыт от поиска (robots + `X-Robots-Tag`).
- Стенд-артефакт в claude.ai: https://claude.ai/artifact/1UoW1GuYSkwJfxsZmrhKaB
- Локально: `npm run stand` → http://localhost:8080.
- Тег `дизайн-варианты-2026-10-10` — код всех вариантов на день выбора.

### Когда купят домен

Вписать его в `site.config.json` → `origin`, добавить имя в `server_name`
(`деплой/a3.nginx.conf`), выпустить сертификат на оба имени и
`деплой/выкатить.sh --nginx`. canonical, sitemap и переадресации с Pages
пересоберутся сами.
