# Ортус — сайт цифрового агентства

Статический сайт (HTML/CSS/JS, без сборки). 23 страницы: главная, хаб услуг,
12 страниц услуг, О нас, Контакты, Кейсы, Блог (+3 статьи), Стать партнёром,
Политика конфиденциальности. SEO-разметка (meta, Open Graph, Schema.org),
sitemap.xml, robots.txt. Формы подключены к Formspree.
